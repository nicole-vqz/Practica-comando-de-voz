# Practica-comando-de-voz
Descargar la versión de `python 3.12.10` para que pueda usar las funciones anteriores en este caso que usaremos el de voz.

Desde la terminal de su computadora `CMD` y utilizando el gestor de paquetes PIP, instalar los paquetes de Python que serán necesarios para esta práctica (PIP se instaló al instalar Python en el paso anterior):
```bash
pip install SpeechRecognition
```
```bash
pip install pyaudio
```
